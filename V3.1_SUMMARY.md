## Critical Fixes (Major Comments)

### 1. ✅ IPW Estimator Mislabeling [CRITICAL]

**Problem**: V3.0 claimed "Horvitz-Thompson (no normalization)" but actually implemented Hájek estimator

**Fix**:
- Correctly identified as **Hájek ratio estimator**
- Added theoretical justification (better finite-sample properties)
- Added option for true HT via `ipw_estimator='horvitz-thompson'`
- Updated all documentation and comments
- Added Hájek (1971) reference

**Impact**: Was theoretically misleading. Now accurate and honest.

**Code Location**: meta_cart_v3_1.py:725-800

---

### 2. ✅ Cost-Complexity Pruning [FUNDAMENTAL ERROR]

**Problem**: Used SE² (estimation variance) instead of prediction MSE

**Fix**:
- Completely rewrote pruning to use **prediction MSE**
- Added `prediction_mse` attribute to Node dataclass
- Now follows Breiman et al. (1984) exactly:
  ```python
  # CORRECT:
  R(T) = prediction MSE (within-node outcome variance)
  α = (R(node) - R(subtree)) / (|leaves| - 1)
  ```

**Impact**: Fundamental algorithm now theoretically correct.

**Code Location**: meta_cart_v3_1.py:703-720, 975-1025

---

### 3. ✅ Propensity SMD Calculation [METHODOLOGICAL ERROR]

**Problem**: Renormalized IPW weights, defeating balance assessment purpose

**Fix**:
- Removed incorrect renormalization
- Now uses proper ATE weights:
  ```python
  # Treated: weight = 1
  # Control: weight = p/(1-p)
  mean_c = np.average(X_control, weights=weights_control)  # NO renormalization
  ```

**Impact**: Balance diagnostics now correctly assess confounding.

**Code Location**: meta_cart_v3_1.py:343-395

---

### 4. ✅ Multiple Testing Dependencies [STATISTICAL VALIDITY]

**Problem**: Holm procedure assumes independence; tree subgroups are dependent

**Fix**:
- Added explicit warnings at initialization
- Recommends FDR method for robustness
- Documented limitations in docstring
- Added Westfall & Young (1993) reference
- Full discussion in `_apply_multiple_testing_correction()` docstring

**Impact**: Users now aware of assumption violations.

**Code Location**: meta_cart_v3_1.py:191-198, 1234-1253
