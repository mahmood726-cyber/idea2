Bug #1 - Cost-Complexity Alpha (Line 774):
  Code:    node_error = node.treatment_effect_se ** 2 * node.n_samples
  Problem: SE already accounts for n, so SE² * n = SD²
  Impact:  Alpha values improperly scaled
  Fix:     node_error = node.treatment_effect_se ** 2

Bug #2 - Holm Monotonicity (Lines 1022-1026):
  Code:    adjusted_p[idx] = min(p[idx] * (k - i), 1.0)
  Problem: Doesn't enforce non-decreasing p-values
  Impact:  May violate FWER control
  Fix:     adjusted_p[idx] = max(adjusted_p[prev], p[idx] * (k - i))

Bug #3 - IPW Normalization (Lines 453-454):
  Code:    weights_treated = weights / sum * len(y_treated)
  Problem: Changes estimand from ATE to something else
  Impact:  BIASED treatment effect estimates
  Fix:     Don't normalize, or normalize to total N

  Code:    error = se ** 2 * len(y_leaf)
  Problem: Penalizes large subgroups, not prediction error
  Impact:  CV may select suboptimal tree
  Fix:     Use MSE or likelihood
